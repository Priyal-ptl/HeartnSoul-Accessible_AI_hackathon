# Heart n Soul — Appointment Planner

A mobile-first web app for people with learning disabilities, autism, and physical disabilities.

Helps users plan and navigate appointments with:
- Clear alerts and friendly language
- Step-by-step transport directions with costs
- Venue photos and floor guidance
- Weather advice
- Read aloud on every section
- Google Calendar and .ics download
- Direct join links for online meetings
